# Assets

Изображения и файлы, вставленные в заметки (`![[имя.png]]`) или
вложения при drag-and-drop, автоматически попадают сюда, если в
Settings → Files & Links → Default location for new attachments указан
путь `(R) Служебные/Assets`. Сама папка пуста в этом комплекте — реальные
изображения не тестовые данные, а бинарные файлы, которые не несут
методологической ценности для примера.

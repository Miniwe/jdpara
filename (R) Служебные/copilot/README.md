# copilot

Служебная папка плагина **Copilot**: история диалогов
(`copilot-conversations`), кастомные промпты (`copilot-custom-prompts`),
системные промпты и память ассистента. Заполняется самим плагином —
ничего сюда не пишется руками, кроме, возможно, кастомных промптов.

Важно для индексации: у Copilot есть настройка `qaExclusions`, в неё
стоит добавить путь до этой же папки (в реальном хранилище —
`copilot`), чтобы плагин не индексировал свою собственную историю как
контент хранилища при построении контекста для ответов. Подробности —
раздел 8 в [[03 Настройка Obsidian|03 Настройка Obsidian]].

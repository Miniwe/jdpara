# Шаблоны

Шаблоны заметок ядра Obsidian (Templates) и Daily notes. Путь этой
папки указывается в двух местах настроек — Settings → Templates →
Template folder, и Settings → Daily notes → Template file (сам файл
шаблона дня внутри этой же папки).

Это шаблоны **формы дня/недели** (что писать в дневник) — не то же
самое, что шаблоны **сущностей методологии** (вопрос/решение/README
проекта), которые лежат в
[[(R) Ресурсы/_шаблоны/README|(R) Ресурсы/_шаблоны]] этого же комплекта.
Разница: эти обслуживают ритм (день, неделя), те — типы файлов внутри
проекта.

Пример шаблона дня — [[Шаблон День]].

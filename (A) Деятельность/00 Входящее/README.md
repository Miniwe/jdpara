# 00 Входящее

**Тестовые данные.** Точка приёма перед сортировкой по Идеям / Вопросам /
Решениям / Экспериментам. Разобранное входящее = пустое входящее — файл
не должен залёживаться, он либо переносится дальше по конвейеру, либо
удаляется, если оказался шумом.

См. пример неразобранной заметки — [[Голосовая заметка про полив соседям]].

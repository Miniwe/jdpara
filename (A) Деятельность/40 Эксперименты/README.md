# 40 Эксперименты

**Тестовые данные.** R&D-песочница уровня области ответственности:
гипотеза → метод → результат → вывод. Как и в проектах, эксперимент без
числа — это не эксперимент, а надежда (см.
[[(R) Ресурсы/Фундамент структуры ведения проекта|Фундамент структуры ведения проекта]]).

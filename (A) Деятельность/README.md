# ⚙️ A · Деятельность

**Тестовые данные.** PARA: Areas — зоны постоянной ответственности без
фиксированного финала: мышление и принятие решений вне рамок конкретного
проекта. В отличие от `(P) Проекты`, здесь не «трекер полива теплицы»
целиком, а разрозненные мысли и вопросы, которые пока не оформлены в
проект (или никогда не станут проектом).

| Подпапка | Роль в конвейере |
|---|---|
| [[00 Входящее/README\|00 Входящее]] | сырой приём: дампы, идеи, неразобранное |
| [[10 Идеи/README\|10 Идеи]] | гипотезы, ещё не оформленные в вопрос или решение |
| [[20 Вопросы/README\|20 Вопросы]] | открытые проблемы и дилеммы, не привязанные к проекту |
| [[30 Решения/README\|30 Решения]] | зафиксированный выбор (ADR) вне рамок конкретного проекта |
| [[40 Эксперименты/README\|40 Эксперименты]] | R&D-песочница: гипотеза → метод → вывод |

Поток: `Входящее → Идеи → Вопросы → Эксперименты → Решения`, дальше —
устоявшееся знание переезжает в `(R) Ресурсы/15 Знания`, а не остаётся
здесь. Разница с `(P) Проекты`: там конвейер привязан к одной цели с
горизонтом, здесь — к области ответственности без финала.

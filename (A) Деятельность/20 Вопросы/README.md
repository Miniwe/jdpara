# 20 Вопросы

**Тестовые данные.** Открытые проблемы, дилеммы, гипотезы, требующие
проверки — но не привязанные к одному проекту (в отличие от
`20-вопросы` внутри `(P) Проекты/*`, которые касаются только своего
проекта). У каждого вопроса обязателен раздел «что изменится от
ответа» — то же правило, что и в проектах, см.
[[(R) Ресурсы/Фундамент структуры ведения проекта|Фундамент структуры ведения проекта]].

Пример — [[Q-A01-стоит-ли-вести-общий-блог-про-автоматизацию]].

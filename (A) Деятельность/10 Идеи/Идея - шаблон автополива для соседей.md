# Идея — шаблон автополива для соседей

**Тестовые данные.** Оформить [[(P) Проекты/01 Пример зрелого проекта/README|трекер полива теплицы]]
как переиспользуемый шаблон (список деталей + прошивка) вместо
разового решения только для своей теплицы.

Пока не вопрос — не блокирует ничего в текущем плане проекта. Если
соседи всё-таки попросят — превратится в вопрос
«стоит ли выделять общий шаблон в отдельный проект».

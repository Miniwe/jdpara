# 🎯 Фокус

**Тестовые данные.** Живой агрегатор — ничего не хранит сам. Отвечает на
вопрос «что сейчас в работе и что там самое важное», а не «сколько всего
открыто» ([[Сводка задач]] — про счётчики, этот файл — про план).

Источник фокуса — поле `приоритет` во frontmatter `README.md` каждого
проекта: `1` = в фокусе, `2` = актуально не сейчас, `3` = фон.

## Проекты в фокусе (приоритет 1)

Правило: держать 2–4 проекта одновременно.

```dataviewjs
const projects = dv.pages('"_STARTER-KIT/(P) Проекты"')
	.where(p => p.file.name === "README" && p.приоритет !== undefined)
	.where(p => p.приоритет === 1)
	.sort(p => p.file.folder);

const count = projects.length;
if (count < 2) {
	dv.paragraph(`🟡 **${count} проект(а) в фокусе** — меньше нижней границы (2).`);
} else if (count > 4) {
	dv.paragraph(`🔴 **${count} проектов в фокусе** — больше верхней границы (4).`);
} else {
	dv.paragraph(`🟢 **${count} проект(а) в фокусе** — в пределах нормы (2–4).`);
}

if (count > 0) {
	dv.table(
		["Проект", "Статус", "Обновлено"],
		projects.map(p => [
			`[[${p.file.path}|${p.file.folder.split("/").pop()}]]`,
			p.status ?? "—",
			p.обновлено ?? "—",
		])
	);
}
```

## Открытые вопросы в проектах фокуса — по приоритету

```dataviewjs
const RANK = { "блокер": 0, "высокий": 1, "обычный": 2, "когда-нибудь": 3 };

const focusProjects = dv.pages('"_STARTER-KIT/(P) Проекты"')
	.where(p => p.file.name === "README" && p.приоритет === 1)
	.sort(p => p.file.folder);

if (focusProjects.length === 0) {
	dv.paragraph("Нет проектов с `приоритет: 1` — список вопросов не строится.");
} else {
	for (const proj of focusProjects) {
		const folder = proj.file.folder;
		const projectName = folder.split("/").pop();

		const questions = dv.pages(`"${folder}/20-вопросы"`)
			.where(p => p.file.name.startsWith("Q-"))
			.where(p => p.status === "открыт");

		dv.header(4, projectName);
		if (questions.length === 0) {
			dv.paragraph("_нет открытых вопросов (или проект не ведёт `20-вопросы`)_");
		} else {
			const rows = questions
				.sort(p => RANK[p.priority] ?? 2)
				.map(p => [`[[${p.file.path}|${p.id}]]`, p.priority ?? "—", p.status ?? "—"]);
			dv.table(["Вопрос", "Приоритет", "Статус"], rows);
		}
	}
}
```

## Как менять фокус

1. Открыть `README.md` нужного проекта, поправить `приоритет:` (1/2/3).
2. Приоритет конкретного вопроса — правкой поля `priority` в самой
   карточке `20-вопросы/Q-….md`.

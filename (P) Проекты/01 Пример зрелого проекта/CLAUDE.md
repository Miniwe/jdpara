# CLAUDE.md — правила работы в этой папке

**Тестовые данные.** Проект: трекер полива теплицы — датчики влажности,
насос, журнал поливов.

Начиная работу, прочитайте [[состояние]] — что уже собрано, что
подтверждено. Затем [[план]] (текущий горизонт), [[README]] (вход).

## Куда что класть

| Что | Куда |
|---|---|
| Факт из документации датчика/контроллера | `15-знание/` (в этом примере пока не заведена — появится с первой заметкой) |
| Развилка, недостающая деталь | `20-вопросы/Q-NNN-имя.md` |
| Сделанный выбор с основанием | `30-решения/D-NNN-имя.md` |
| Выдержка из даталиста как есть | `10-источники/` — не редактировать после записи |
| Неразобранное | `00-входящие/` |

## Обязательные поля frontmatter

Ключи латиницей, значения по-русски — см. примеры в `20-вопросы/` и
`30-решения/` этого проекта.

## Секреты

Wi-Fi пароль теплицы и токен MQTT-брокера сюда не попадают — только
имена переменных окружения контроллера.

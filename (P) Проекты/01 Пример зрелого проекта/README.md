# Пример зрелого проекта

**Тестовые данные.** Demo-проект «трекер полива теплицы»: датчики влажности
шлют показания, приложение решает, когда включать насос, и держит журнал
поливов. Используется, чтобы показать, как выглядит проект, прошедший
несколько сессий работы: с накопленными вопросами, принятыми решениями
и живым дашбордом состояния.

## Новая сессия начинает отсюда

1. [[состояние]] — что уже собрано, что подтверждено, что нет
2. [[план]] — текущий горизонт
3. [[журнал]] — хронология

## Структура

```
README.md          ← этот файл
CLAUDE.md           ← правила работы для ИИ-агента
состояние.md        ← дашборд
план.md             ← текущий горизонт, без галочек
журнал.md           ← append-only лог
00-входящие/        ← сырое, неразобранное
10-источники/       ← неизменяемые оригиналы
20-вопросы/         ← открытые развилки, префикс Q-
30-решения/         ← зафиксированный выбор, префикс D-
```

# D-001. Контроллер — ESP32, не Raspberry Pi Zero

## Контекст

Нужен контроллер для одной теплицы: читать один датчик влажности,
управлять одним реле насоса. Rasp Pi Zero был исходным вариантом по
привычке (уже использовался в другом проекте).

## Решение

Использовать ESP32 вместо Raspberry Pi Zero.

## Основание

- ESP32 дешевле (~$4 против ~$15) и не требует SD-карты и полноценной ОС;
- задача не требует Linux — только опрос АЦП и управление GPIO по Wi-Fi;
- энергопотребление ESP32 в разы ниже — важно при питании от той же сети,
  что и насос.

## Отвергнутые варианты

| Вариант | Почему отвергнут |
|---|---|
| Raspberry Pi Zero | избыточен для задачи, дороже, требует SD-карту и загрузку ОС |
| Arduino Uno без Wi-Fi | нет встроенной связи, нужен отдельный Wi-Fi-модуль — усложняет схему без выгоды |

## Последствия

Код пишется на Arduino-фреймворке (C++), а не на Python — влияет на все
дальнейшие эксперименты и заметки знания об этом проекте.

## При каких новых фактах пересматриваем

Если теплиц станет больше одной и понадобится локальный сервер
агрегации — тогда общий Raspberry Pi как хаб может иметь смысл рядом с
несколькими ESP32, а не вместо них.

# Пример простого проекта

**Тестовые данные.** Demo-проект «подготовка к переезду»: разовая
активность с понятным концом, без исследовательской части — поэтому не
нужны `20-вопросы`/`30-решения` в стиле Johnny.Decimal. Показывает второй
допустимый профиль проекта: не всё обязано быть тяжёлой методологией.

## Структура

```
README.md      ← этот файл
Задачи.md       ← плоский список дел с чекбоксами Tasks
```

Когда/если проект вырастет (появятся развилки, требующие фиксации
основания выбора) — можно взять
[[Шаблон CLAUDE проекта|_STARTER-KIT/(R) Ресурсы/_шаблоны/Шаблон CLAUDE проекта]]
и добрать `20-вопросы`/`30-решения`, как в
[[01 Пример зрелого проекта/README|Пример зрелого проекта]]. Не обязательно
заводить полную структуру заранее.

# 20 Questions

**Test data.** Open problems, dilemmas, and hypotheses that need
checking — but not tied to a single project (unlike the `20-questions`
inside `(P) Projects/*`, which only concern their own project). Every
question must have a "what changes with the answer" section — the same
rule as in projects, see
[[(R) Resources/Foundation of project structure|Foundation of project structure]].

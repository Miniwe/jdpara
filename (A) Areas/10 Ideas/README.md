# 10 Ideas

**Test data.** A raw inbox of thoughts and hypotheses already separated
from noise, but not yet shaped into a question or decision. An entry
point for new content, later distributed through the system — if an idea
goes stale and nothing would change by acting on it, it doesn't move
further, it just stays here as a dead end.

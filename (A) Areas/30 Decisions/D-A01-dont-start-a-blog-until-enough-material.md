# D-A01. Don't start a blog until enough material builds up

## Context

[[../20 Questions/Q-A01-should-we-run-a-shared-automation-blog|Q-A01]]:
so far there's only one fully worked-out case (greenhouse watering).

## Decision

Hold off on starting a separate blog project until a second independent
automation case shows up.

## Rationale

One case isn't a series, it's a coincidence; a one-post blog doesn't
justify separate infrastructure (accounts, publishing process).

## Rejected alternatives

| Option | Why rejected |
|---|---|
| Start the blog right away | no second case yet — high risk the motivation fades after one post |

## Consequences

The [[../10 Ideas/Idea - auto-watering template for neighbors|idea about a template for the neighbors]]
stays local, with no publication.

## What new facts would prompt a revisit

A second, independent automation project at the level of the watering
tracker shows up — then the question reopens.

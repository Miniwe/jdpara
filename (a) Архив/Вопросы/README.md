# Архив · Вопросы

**Тестовые данные.** Вопросы со статусом `отвечен`/`снят`/`протух`,
которые больше не нужны в рабочем поле проекта, но не удаляются — ответ
может понадобиться как справка позже. Перенос не меняет `id` вопроса.

Этот пример комплекта пока не содержит закрытых вопросов — оба вопроса
в [[(P) Проекты/01 Пример зрелого проекта/README|Примере зрелого проекта]]
ещё открыты. Когда `Q-001`/`Q-002` получат ответ, сюда переносится сам
файл вопроса (не копия), как только он перестанет быть нужен в
`20-вопросы` проекта.

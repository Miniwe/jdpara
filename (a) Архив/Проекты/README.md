# Архив · Проекты

**Тестовые данные.** Завершённые проекты переносятся сюда целиком —
папка со всей своей внутренней структурой (README, CLAUDE.md,
`20-вопросы`, `30-решения` и т.д.), без разборки на части. Вики-ссылки
из других файлов на этот проект продолжают работать, если имя файла не
менялось при переносе.

Пример — [[00 Пример завершённого проекта/README|00 Пример завершённого проекта]]:
демо-проект «настройка Wi-Fi в теплице», который был решён за один
вечер и не потребовал полноценной методологии.

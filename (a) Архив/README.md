# 🗄️ a · Архив

**Тестовые данные.** PARA: Archives. Повторяет структуру `P/R/A`, но
плоско — без глубокой вложенности. Сюда **перемещается** (не
копируется) всё завершённое: закрытые проекты целиком, закрытые
вопросы, неудачные эксперименты, отработанные логи журнала. Номер и
вики-ссылки при переносе не меняются — только физическое место файла.

| Подпапка | Что сюда попадает |
|---|---|
| [[Проекты/README\|Проекты]] | завершённые проекты целиком, из `(P) Проекты` |
| [[Вопросы/README\|Вопросы]] | закрытые вопросы (из проектов или из `(A) Деятельность`) |
| [[Эксперименты/README\|Эксперименты]] | отработанные эксперименты — и успешные, и неудачные |
| [[Журнал/README\|Журнал]] | дневные логи старше календарного порога (например, помесячно) |

## Когда переносить

Проект — когда цель достигнута или окончательно снята (не «пауза», это
`приоритет: 3`, а именно конец). Вопрос/эксперимент — когда статус
`отвечен`/`снят`/эксперимент завершён выводом. Пока рано — файл остаётся
в `(P) Проекты` или `(A) Деятельность`, архив не для «пока не до этого».

# Архив · Эксперименты

**Тестовые данные.** Отработанные эксперименты — и с подтверждённой
гипотезой, и с отрицательным результатом. Отрицательный результат
хранится с той же дисциплиной, что и положительный — он экономит время
на повторную проверку той же гипотезы позже.

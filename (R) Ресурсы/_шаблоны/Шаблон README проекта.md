
## Правила ведения

Полные правила — в [[CLAUDE]] этого проекта. Ключевое:

1. Каждый шаг — строка в [[журнал]], новые снизу.
2. Источник не редактируется — ошибка в источнике фиксируется в знании,
   а не правится на месте.
3. Вопрос без раздела «что изменится от ответа» не заводится.
4. Секреты не попадают в файлы этого хранилища.

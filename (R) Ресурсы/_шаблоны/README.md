# _шаблоны

Заготовки для типов файлов методологии — копируются в проект и
заполняются. Не то же самое, что
[[(R) Служебные/Шаблоны/README|(R) Служебные/Шаблоны]] — там шаблоны
ритма (день/неделя), здесь — шаблоны сущностей.

| Шаблон | Копировать при создании |
|---|---|
| [[Шаблон README проекта]] | нового проекта в `(P) Проекты` |
| [[Шаблон CLAUDE проекта]] | правил для ИИ-агента внутри нового проекта |
| [[Шаблон вопрос]] | новой карточки в `20-вопросы/Q-NNN-имя.md` |
| [[Шаблон решение]] | новой карточки в `30-решения/D-NNN-имя.md` |

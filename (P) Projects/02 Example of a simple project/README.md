# Example of a simple project

**Test data.** Demo project "getting ready to move": a one-off activity
with a clear end, no research component — so no `20-questions`/
`30-decisions` in the Johnny.Decimal style. Shows the second valid
project profile: not everything has to carry the full methodology.

## Structure

```
README.md      ← this file
Tasks.md        ← a flat to-do list with Tasks-plugin checkboxes
```

If/when the project grows (forks come up that need a documented
rationale) — you can take the
[[Project CLAUDE template|JDPARA-EN/(R) Resources/_templates/Project CLAUDE template]]
and add `20-questions`/`30-decisions`, as in
[[01 Example of a mature project/README|Example of a mature project]]. No
need to set up the full structure in advance.

## Tasks

See [[Tasks]] — priorities are set using the Tasks plugin's syntax
(🔺/⏫/🔼), since there are no question cards here to derive them from.

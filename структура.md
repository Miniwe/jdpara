# Структура этого комплекта

Карта за одну страницу. Полное обоснование — в
[[(R) Ресурсы/Фундамент структуры ведения проекта|Фундамент структуры ведения проекта]].

## Корень

| Файл | Роль |
|---|---|
| [[Фокус]] | какие проекты сейчас в фокусе и что там самое важное — читает frontmatter проектов |
| [[Сводка задач]] | счётчик открытых задач по всем проектам |
| [[Канбан-доска]] | ручная доска верхнего уровня — вход без раздумий, не для проектов |

## (P) Проекты

PARA: Projects. Каждый проект — папка с собственным README и (опционально)
CLAUDE.md. Внутри проекта — Johnny.Decimal-префиксы для типов содержимого:
`00-входящие`, `10-источники`, `20-вопросы`, `30-решения`. Не каждый
проект обязан использовать все префиксы — см. разницу между
[[(P) Проекты/01 Пример зрелого проекта/README|01 Пример зрелого проекта]]
(полный набор) и [[(P) Проекты/02 Пример простого проекта/README|02 Пример простого проекта]]
(только README + плоский список задач).

## (R) Ресурсы

PARA: Resources. Методология и шаблоны, не привязанные к конкретному
проекту. `_шаблоны/` — заготовки для README, CLAUDE, вопроса, решения:
копируются в проект и заполняются.

## (A) Деятельность

PARA: Areas. Тот же конвейер, что и внутри проекта (входящее → идея →
вопрос → решение → эксперимент), но для того, что не привязано ни к
одной цели с горизонтом — область постоянной ответственности без
финала. См. [[(A) Деятельность/README|README]] этой папки.

## (A) Журнал

Один файл на день (`ГГГГ-ММ-ДД.md`), три зоны: фокус дня, чек-листы,
входящий лог. Разбирается в `(A) Деятельность`/`(P) Проекты` по мере
накопления, сам файл дня уходит в `(a) Архив/Журнал` по календарному
порогу, не сразу после разбора.

## (a) Архив

PARA: Archives. Повторяет `P/R/A`, но плоско. Сюда **перемещается** (не
копируется) завершённое: проекты целиком, закрытые вопросы,
отработанные эксперименты, старые дни журнала. См.
[[(a) Архив/README|README]] этой папки.

## (R) Служебные

Техническая инфраструктура — вне контура P.A.R.A., не участвует в
конвейере знаний: вложения, аудио, служебные данные Copilot, шаблоны
ритма (день/неделя). См. [[(R) Служебные/README|README]] этой папки.

## Принцип движения

Сырое (`00-входящие`) → осмысленное (`20-вопросы`, обсуждение) →
закреплённое (`30-решения`, `15-знание`). Обратного движения нет —
пересмотр решения — это новое решение со ссылкой на старое, а не правка
старого.

# Templates

Note templates for Obsidian's core Templates feature and Daily notes.
This folder's path is set in two places in Settings — Settings →
Templates → Template folder, and Settings → Daily notes → Template file
(the day template file itself lives inside this same folder).

These are **day/week-form** templates (what to write in the journal) —
not the same as the **methodology-entity** templates
(question/decision/project README), which live in
[[(R) Resources/_templates/README|(R) Resources/_templates]] in this
same kit. The difference: these serve the rhythm (day, week), those serve
the file types inside a project.

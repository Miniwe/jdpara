# Audio

Voice notes and audio recordings (meetings, conversations) that go
through the **AI Audio Transcription & Summary** plugin — it turns a
recording into a text transcript, which then lands in
`(A) Areas/00 Inbox` or directly in a project, like any other incoming
material (an example of such processing is [[(A) Areas/00 Inbox/Voice note about watering for neighbors|Voice note about watering for neighbors]],
though in reality it would have come from a file here rather than being
typed out as text).

The `Meetings`/`Recordings` subfolders in a real vault are just a
grouping by recording type, not a required part of the methodology.

# Assets

Images and files embedded in notes (`![[name.png]]`) or dropped in via
drag-and-drop land here automatically if Settings → Files & Links →
Default location for new attachments is set to `(R) Utility/Assets`. The
folder itself is empty in this kit — real images aren't test data, they're
binary files with no methodological value for the example.

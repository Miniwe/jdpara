# ⚙️ R · Utility

Technical infrastructure for the vault — outside the P.A.R.A. loop, not
part of the knowledge pipeline (inbox → idea → question → decision).
There are no test notes "about content" here, just a description of what
each subfolder is for and related plugin settings — real attachments,
audio, and chat history are deliberately not copied into this kit.

| Subfolder | What goes here | Setting |
|---|---|---|
| [[Assets/README\|Assets]] | images and attachments embedded in notes | Settings → Files & Links → Default location for new attachments: `(R) Utility/Assets` |
| [[Audio/README\|Audio]] | voice notes/audio recordings | destination folder for the AI Audio Transcription & Summary plugin |
| [[copilot/README\|copilot]] | the Copilot plugin's own data: conversation history, custom prompts, memory | path set in the Copilot plugin's settings, see [[03 Obsidian setup|Obsidian setup]] |
| [[Templates/README\|Templates]] | note templates (Templates / Daily notes) | Settings → Templates → Template folder: `(R) Utility/Templates`; Daily notes → Template file |

Details for each plugin (exactly what to enable, which values to set) —
in [[03 Obsidian setup|03 Obsidian setup]]. This file is only about what
the folders are for, not about the plugin settings themselves.

# 🗄️ a · Archive

**Test data.** PARA: Archives. Mirrors the `P/R/A` structure, but flat —
with no deep nesting. This is where everything finished **moves** (not
copies) to: whole closed projects, closed questions, failed experiments,
completed journal logs. The id and wikilinks don't change on the move —
only the file's physical location.

| Subfolder | What goes here |
|---|---|
| [[Projects/README\|Projects]] | whole finished projects, from `(P) Projects` |
| [[Questions/README\|Questions]] | closed questions (from projects or from `(A) Areas`) |
| [[Experiments/README\|Experiments]] | completed experiments — both successful and unsuccessful |
| [[Journal/README\|Journal]] | daily logs older than the calendar threshold (e.g., monthly) |

## When to move something

A project — when its goal is achieved or permanently dropped (not
"paused," that's `priority: 3` — this means an actual end). A
question/experiment — when its status is `answered`/`dismissed`, or an
experiment has concluded with a finding. If it's too soon — the file
stays in `(P) Projects` or `(A) Areas`; the archive isn't for "not
getting to it yet."

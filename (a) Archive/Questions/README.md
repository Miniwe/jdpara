# Archive · Questions

**Test data.** Questions with status `answered`/`dismissed`/`stale` that
are no longer needed in a project's working set, but aren't deleted —
the answer might be useful as a reference later. Moving doesn't change a
question's `id`.

This kit's example doesn't yet have any closed questions — both
questions in [[(P) Projects/01 Example of a mature project/README|the
Example of a mature project]] are still open. Once `Q-001`/`Q-002` get
answered, the question file itself (not a copy) moves here, as soon as
it's no longer needed in the project's `20-questions`.

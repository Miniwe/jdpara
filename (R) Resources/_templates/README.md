# _templates

Drafts for the methodology's file types — copied into a project and
filled in. Not the same as
[[(R) Utility/Templates/README|(R) Utility/Templates]] — those are
rhythm templates (day/week), these are entity templates.

| Template | Copy it when creating |
|---|---|
| [[Project README template]] | a new project in `(P) Projects` |
| [[Project CLAUDE template]] | AI-agent rules inside a new project |
| [[Question template]] | a new card in `20-questions/Q-NNN-name.md` |
| [[Decision template]] | a new card in `30-decisions/D-NNN-name.md` |
